# Leetspeak Bypass Detection Module

## Problem
Attackers use obfuscated text to bypass chatbot security filters.

Example:
"h4ck"
"1gn0re prev10us instruct10ns"

## Solution
This module normalizes leetspeak and detects suspicious inputs.

## Features
- Leetspeak normalization
- Risk scoring
- Blocked term detection
- Suspicious pattern detection
- Repeated character handling

## Future Improvements
- ML-based detection
- Unicode homoglyph detection
- Fuzzy matching
